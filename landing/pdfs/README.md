README – Gestor de Sueldos – Cooperativa 25 de Mayo Ltda.

Presentación General
El Gestor de Sueldos es un sistema web desarrollado para la Cooperativa de Servicios Públicos 25 de Mayo Ltda., con el objetivo de optimizar y modernizar la gestión administrativa relacionada con empleados, convenios laborales y liquidación de sueldos.
El software permite automatizar cálculos, reducir tiempos administrativos, minimizar errores manuales y mantener un registro ordenado y seguro de todas las operaciones relacionadas a la liquidación salarial.

Este proyecto fue desarrollado por estudiantes de la Tecnicatura Universitaria en Programación (UTN), adaptado a las necesidades reales de la cooperativa y con potencial para escalar a más módulos en el futuro.

──────────────────────────────────────────────

Objetivos del Sistema
– Facilitar la carga, consulta y edición de empleados.
– Gestionar convenios laborales, categorías y montos salariales.
– Automatizar la liquidación de sueldos para cada empleado.
– Calcular conceptos remunerativos, no remunerativos, descuentos y retenciones.
– Obtener el neto a cobrar de forma clara y verificable.
– Generar recibos e historial de liquidaciones.
– Ofrecer una interfaz clara, moderna y fácil de usar.

El objetivo final es mejorar la eficiencia administrativa, reducir errores y brindar una herramienta profesional adaptada a las normas laborales vigentes.

──────────────────────────────────────────────

Funcionalidades Principales

Gestión de Empleados
– Alta, baja y modificación de empleados.
– Listado dinámico con filtros y búsqueda.
– Datos organizados de manera clara para una rápida revisión.

Gestión de Convenios
– Creación y administración de convenios laborales.
– Configuración de categorías, montos base y reglas salariales.
– Organización simple y eficiente de escalas salariales.

Liquidación de Sueldos
– Cálculo automático basado en convenio y categoría.
– Carga de conceptos remunerativos y no remunerativos.
– Cálculo de aportes, retenciones, descuentos y neto final.
– Generación del recibo listo para guardar o imprimir.

Interfaz del Sistema
– Diseño intuitivo y orientado al uso real dentro de la cooperativa.
– Tablas organizadas, botones claros y navegación sencilla.
– Pensado para minimizar errores y acelerar las tareas rutinarias.

Sección Técnica (para responsables o desarrolladores)

Tecnologías del Frontend
– React
– TypeScript
– React-Bootstrap
– TanStack React Table
– TanStack Virtual
– Arquitectura modular con componentes reutilizables
– Hooks personalizados
– CSS moderno y responsivo

Tecnologías del Backend
– Java
– Spring con JPA/Hibernate
– API REST con endpoints estructurados
– Manejo de roles y validaciones de datos
– Lógica de negocio centralizada

Base de Datos
– PostgreSQL
– Tablas para empleados, convenios, categorías, liquidaciones y recibos
– Integración vía ORM

Arquitectura del Sistema
Frontend (React) se comunica con Backend (Java) mediante JSON.
El backend gestiona la lógica, validaciones y persistencia.
La base de datos almacena toda la información.
Arquitectura pensada para mantenimiento simple y escalabilidad futura.
